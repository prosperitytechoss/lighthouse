# Security

Lighthouse runs on children's phones. Please report problems privately.

Email hello@prosperitytech.org with a description and steps to reproduce. We reply within three working days and fix confirmed issues before disclosing them.

Do not open a public issue for a security problem.

What counts: anything that leaks message text, screen images or location off the device, anything that lets a fork receive updates meant for the official app, anything that lets one parent see another family's data.

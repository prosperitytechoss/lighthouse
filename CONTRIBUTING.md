# Contributing

Thank you for helping keep children safe online.

## Ways to help

- Words. If you speak Nigerian Pidgin, Yoruba, Hausa or Igbo, the most useful thing you can do is improve the word lists. See CONTRIBUTING-LEXICON.md. Words are reviewed by a person before they reach any phone.
- Code. Bug fixes and small improvements are welcome as pull requests. Open an issue first for anything large.
- Testing. Real phones matter more than emulators. Tell us what breaks on yours.

## Ground rules

- Child data never leaves the phone. Any change that sends message text, screen images or location off the device will not be merged.
- Copy is plain. Short sentences, no jargon, no dashes.
- No code comments. Names should carry the meaning.
- Run `yarn type-check` and `yarn lint` before you push.
